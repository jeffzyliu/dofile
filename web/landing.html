About dofile

Run Stata-syntax do-files in your browser. No license, no account: the engine runs inside this page, on your own computer.

What it is: an open-source interpreter for Stata-syntax code, built on OpenDTA (MIT). It reads and writes .dta files, fits the common estimators and draws graphs. Not every command exists yet: the list is under Commands, at the top of the page.

Your files: files you open stay in this browser; they are not sent anywhere. The first visit downloads the engine (Python compiled to WebAssembly, about {{engine-mb}} MB).

Also on your computer, and for AI agents: the same engine as a command line (dofile run) and as an MCP server, so an AI agent can run do-files for you.

Where it comes from: the interpreter is OpenDTA, by its own authors. dofile adds the sandbox, this page, the command line and the MCP server.

Browsers that work

dofile runs in the page, so the browser needs WebAssembly, IndexedDB (where your files are kept) and enough memory for the engine, which needs a little over 1 GB while it starts.

  • Chrome, Edge, Firefox and Safari on a computer. Checked by automatic tests in Chromium, Firefox and WebKit (the engine Safari is built on).
  • iPhone and iPad (Safari). Tried by hand on one iPhone, once, and the tests run an iPhone-sized window. Not checked on other models: a phone with little memory may fail to start the engine, and the page then says so.
  • Android (Chrome, Firefox). Expected to work the same way. Not tried on a real phone yet.

The Break button needs a page the browser treats as isolated from other sites; this site is served that way. If a browser or a network does not allow it, Break resets the engine instead of stopping the run. Your files stay in the browser's own storage: if a browser clears it or refuses it, the page says so, and "Download all (.zip)" in the file menu keeps a copy.
