Commands

The {{command-count}} commands the dofile engine has today, read from the engine's own list when this page was built. In each name, the bold letters are the shortest form you can type.

A name here means the engine knows the command, not that every option of it works. The engine is checked against results recorded from Stata 14 for a set of test programs; anything outside that set may differ. In this page {{denied}} are switched off, since a browser page cannot run programs or download files. Loops, if and else, programs and macros are part of the language itself and may not appear in the list.
