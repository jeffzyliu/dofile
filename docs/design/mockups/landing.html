About dofile

    
    

      
Run Stata-syntax do-files in your browser. No license, no account: the engine runs inside this page, on your own computer.

      
What it is: an open-source interpreter for Stata-syntax code, built on OpenDTA (MIT). It reads and writes .dta files,
        fits the common estimators and draws graphs. Not every command exists yet: the list is under Commands, at the top of the page.

      
Your files: files you open stay in this browser; they are not sent anywhere. The first visit downloads the engine
        (Python compiled to WebAssembly, about 36 MB) from a public CDN.

      
Also on your computer, and for AI agents: the same engine as a command line (dofile run) and as an MCP server, so an
        AI agent can run do-files for you.

      
Where it comes from: the interpreter is OpenDTA, by its own authors. dofile adds the sandbox, this page, the command
        line and the MCP server.

On your computer

      
Command line and MCP server with the first release

      
pip install dofile

      
Today, from the source

      
claude mcp add dofile -- uv run --directory /path/to/dofile --extra mcp dofile-mcp --workdir "$PWD"Copied

      
Replace /path/to/dofile with the folder you cloned dofile into.
