B. Editor and one output pane: files | editor | Log · Graph · Data · Results · Help

  • For: two big panes; the editor is about 80 columns and the log has room to spare; it scales down to a laptop, and it is the same model as the phone's tabs.
  • Against: after scatter the graph is one click away, not in view. A new graph shows as a small preview over the log's corner (dismissable) and a dot on the Graph tab; the tab does not switch by itself, so the log stays where you were reading.
  • The command line sits under the output pane on every tab, so you can type describe while looking at Data.
  • Split (chosen 2026-11-09, desktop-b-split.png): "Split" in the output header puts the Log on top and the other tabs below, Graph first; then a new graph shows below at once, with no preview. The choice is kept in the browser.
  • Focus order: toolbar 1, files 2, editor 3, output tabs 4, command line 5 (split: then the lower pane 6). F6 / Shift+F6 between panes; arrow keys move between tabs (ARIA tablist).
  • Status lives only in the bottom bar (a live region): engine state, last rc and time, memory. The toolbar holds actions only. The wordmark links to the landing page; ⋯ holds Reset, Clear log, Download all, Keyboard shortcuts and About dofile.
