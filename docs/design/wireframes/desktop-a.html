A. Everything visible: files | editor over data | log over graph

  • For: after scatter you see the log and the graph at once; the data's variables stay in view while you type, and a click inserts a name.
  • Against: six regions at 1440 px; the editor is about 55 columns wide and the log just fits its 78. Below about 1280 px the graph has to fold into the data tabs (that is layout B).
  • Each pane can be collapsed to its header and the dividers dragged; the layout is kept in the browser.
  • Results and Help share the tabbed pane with Data; help regress switches it to Help.
  • Focus order (red numbers): toolbar 1, files 2, editor 3, log 4 (then its command line), graph 5, data tabs 6. F6 / Shift+F6 moves between panes; each pane is a labeled region.
  • The status bar is a live region: start-up stages, running, Break, reset and rc are read out.
  • The log is text (not an image), so a screen reader reads tables line by line; errors are links to the line.
  • Shortcuts: Ctrl/Cmd+Enter run (selection or file), Ctrl/Cmd+S save, Ctrl/Cmd+. Break, Ctrl/Cmd+L command line.
